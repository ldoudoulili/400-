# 如何把项目重新打包成 400维修记录.exe

这个 exe 用的是 Node 官方 SEA（Single Executable Application）方案，
直接复用本机 node.exe 打包，**不需要从网络下载任何东西**，做出来的 exe 自带运行时，
在没装 Node.js 的电脑上也能双击运行。

## 前提
- 本机有 node（版本 ≥ 20.12）
- 本机有 python 3 + pefile（用于移签，已装过：`python -m pip install pefile`）
- 本机可访问 npm registry（用于 npx 下载 postject，已可用）

## 打包步骤（在项目根目录执行）

```powershell
Set-Location "D:\Project\GITEE\400电话维修记录"

# 1) 生成 SEA blob（内容 = server.js 快照）
#    注意：sea-config.json 的 main 路径是【相对当前工作目录】解析的，
#    所以必须先在 .pack 目录下运行（此时 main=../server.js 指向项目根的 server.js）。
Set-Location .pack
node --experimental-sea-config sea-config.json
Set-Location ..

# 2) 用干净的本机 node.exe 作为基底，复制成目标 exe
$node = (Get-Command node).Source
Copy-Item -LiteralPath $node -Destination "400维修记录.exe" -Force

# 3) 移签 + 改成 GUI 子系统（不弹黑窗）。此步会修改 400维修记录.exe
python .pack\remove_sig_gui.py "400维修记录.exe"

# 4) 注入 SEA blob
npx -y postject "400维修记录.exe" NODE_SEA_BLOB .pack\sea-prep.blob `
    --sentinel-fuse NODE_SEA_FUSE_fce680ab2cc467b6e072b8b5df1996b2

# 5) 清理中间产物
Remove-Item .pack\sea-prep.blob -Force
```

## 为什么改 server.js 后必须重新打包
exe 里的代码是打包那一刻 server.js 的**快照**（嵌入在 exe 里，不读取外部 server.js）。
所以每次改了 server.js 都要重新走上面 1~4 步，新 exe 才会带上新功能。

## 发布时拷哪些文件
exe 运行时页面和数据都从 exe **旁边**读取：
- `400维修记录.exe`（本体）
- `page\`（页面文件夹，必须和 exe 同一目录）
- `data.json`（数据，首次运行会自动创建，没有也没关系）

把这三样（或整个项目文件夹）发给别人即可，对方**不需要装 Node.js**。

## 说明
- `remove_sig_gui.py`：移除 node.exe 的数字签名（否则 SEA 注入后无法运行）+ 把子系统改成 GUI（双击不弹黑窗）。
- `sea-config.json`：SEA 配置，main 指向上一级 server.js。
